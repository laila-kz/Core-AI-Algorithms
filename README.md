# Core AI Algos

This repository collects implementations and experiments for several machine learning models and techniques (CNNs, RNNs, boosting, random forests, fuzzy systems, etc.).

Key folders
- `random_forest/` — experiments and notebooks for isolation forest and random forest intrusion detection.
- `boosts/`, `CNN/`, `neural_network/`, `fuzzy_intelligent_systems/` — other experiments and notebooks.

How to present the Random Forest work on GitHub
1. Browse to `random_forest/notebooks/` to view the analysis and training notebooks.
2. Read `random_forest/README.md` and `random_forest/SHOWCASE.md` for a concise project summary and instructions.
